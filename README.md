# 복싱 스파링 매칭 앱 (가칭 '맞수') — 프로토타입

여가레크리에이션교육론 팀 과제3 초안입니다. 복싱 스파링 상대를 실력·체급·성별 기준으로 찾아 주고, 링 예약부터 스파링 후 리포트까지 이어지는 흐름을 보여 주는 웹 프로토타입입니다.

**앱 열기**: https://leisure-recreation.github.io/boxing-sparring-app/

## 들어 있는 것
- 이용자 화면: 홈, 찾기(정규 매칭·지도 스파링·스파링 데이), 일정, 기록, 내 정보
- 체육관 콘솔: 레벨 인증, 링·대진 관리, 스파링 데이 대진 편성, 사고·정산
- 오른쪽 위 `이용 안내`에 이용자 화면과 체육관 화면 사용법이 있습니다.
- `내 정보` 탭의 시연 도구로 상대 수락이나 시간 경과를 흉내 낼 수 있습니다.
- `앱_개발운영_고려사항_1-7.pdf`: 개인정보, 홍보, 심판 수급, 참여비, 책임 소재, 리그전, 타종목 확장성 정리

## 알아 둘 점
- 시연용입니다. 결제와 본인인증은 모의 기능입니다.
- 체육관 이름('예시복싱')은 가상이며 실제 체육관과 제휴한 것이 아닙니다.
- 참가비 금액과 동의서 문구는 가정·예시입니다.
- 데이터는 각자 브라우저에만 저장되며, 날짜가 바뀌면 시연 데이터가 초기화됩니다.
- 영상 AI 분석은 범위에서 제외했습니다.
